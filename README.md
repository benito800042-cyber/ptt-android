# PTT Android · Canal de taxis

APK independiente del prototipo PTT local para taxis. Incluye identidad local editable (nombre, teléfono y taxi), botón circular push-to-talk y número del hablante simulado.

**Importante:** esta APK es un prototipo local: todavía no hay voz real entre teléfonos. El micrófono solo se solicita al pulsar PTT y no se envía audio.

El proyecto empaqueta la interfaz WebView local (`index.html`, `styles.css`, `app.js`) y GitHub Actions compila el APK debug y publica releases para etiquetas `v*`.
